Stardust Turntable - 내 음악 폴더 재생

1) music 폴더에 음원(mp3, m4a, wav, flac, ogg)을 넣습니다. 하위 폴더도 읽어요.
   - 같은 이름의 .lrc / .srt / .vtt 파일이 있으면 자막으로 나옵니다.
     예) 노래.mp3 + 노래.lrc
   - 같은 이름의 이미지(노래.jpg)나 폴더의 cover.jpg가 있으면 그 색으로 물듭니다.
     mp3는 안에 들어 있는 앨범 이미지를 먼저 씁니다.
   - 자막 파일이 없으면 인터넷에서 시간 맞춘 가사를 자동으로 찾아봅니다.
2) 실행합니다.
   - Windows: start.bat 더블클릭
   - Mac: start.command 더블클릭 (처음에는 우클릭 > 열기)
   - 직접: python3 serve.py   (Python 3 필요)
3) 브라우저가 열리면 오른쪽 위 "내 음악"에서 곡을 고릅니다.

옵션
  python3 serve.py --music ~/Music   다른 음악 폴더 사용
  python3 serve.py --port 9000       포트 변경
  python3 serve.py --host 0.0.0.0    같은 와이파이의 폰에서 접속

서버 없이 쓰려면 index.html을 열고 "내 음악 > 폴더 선택"으로 폴더를 고르세요.
(페이지를 닫으면 선택이 풀리고, 유튜브 재생은 파일로 직접 열면 막힐 수 있어요.)

턴테이블 조작 (별로 된 LP 플레이어 위에서)
  - 오른쪽 아래 둥근 버튼: 재생 / 정지 (곡이 끝나도 눌러서 다시 재생)
  - 그 왼쪽의 작은 버튼 두 개: 이전 곡 / 다음 곡 (내 음악에서 여러 곡을 열었을 때)
  - 오른쪽 슬라이더: 재생 위치. 손잡이를 끌어서 이동하고, 위쪽에 현재 시간 / 전체 길이가 나와요
  - LP 판: 판을 잡고 돌리면 재생 위치가 바뀌어요 (시계 방향 = 앞으로, 반대 = 뒤로). 돌리는 동안은 소리가 멈추고 놓으면 이어서 재생돼요
  - 왼쪽 위 노브: 볼륨 (드래그, 휠, 더블클릭으로 음소거)
  키보드: 스페이스 재생/정지, ← → 5초 이동, ↑ ↓ 볼륨, N / P 다음 / 이전 곡

이펙트: 별이 모여 완성될 때, 곡이 바뀔 때, 버튼을 누르거나 LP를 돌렸다 놓을 때, 자막이 바뀔 때, 내 음악의 비트(저음)에 맞춰 판 가장자리에서 별가루가 팡 터져요. 유튜브 재생에서는 소리를 분석할 수 없어서 은은한 불꽃이 일정하지 않은 간격으로 터져요. 브라우저의 '동작 줄이기' 설정을 켜면 꺼져요.

보관한 유튜브 곡: 재생 중 '보관'을 눌러 담아 두면, LP 위의 이전/다음 버튼(또는 P / N 키)으로 보관한 곡들을 차례로 넘길 수 있어요. 보관하지 않은 곡이 끝나면 보관함의 첫 곡으로 넘어가요.

배경: 턴테이블이 완성된 뒤에도 배경에는 별들이 계속 천천히 떠다녀요.
