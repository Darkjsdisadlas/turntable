# Stardust Turntable

별가루로 완성되는 인터랙티브 턴테이블 웹 플레이어입니다. YouTube 링크를 재생하거나, 방문자가 자신의 음악 폴더를 선택해 로컬 음원을 들을 수 있습니다.

## 공개 사이트로 사용하기

이 프로젝트는 GitHub Pages용 자동 배포 설정을 포함합니다.

1. GitHub에서 새 저장소를 만들고 이 폴더의 내용을 `main` 브랜치에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. `main` 브랜치에 푸시하면 배포가 자동으로 시작됩니다. 완료된 사이트 주소는 **Actions** 실행 결과 또는 **Settings → Pages**에서 확인할 수 있습니다.

GitHub Pages에서는 서버가 방문자의 컴퓨터에 있는 음악 폴더를 읽을 수 없습니다. 대신 사이트 오른쪽 위의 **내 음악 → 폴더 선택**에서 각 방문자가 직접 음악 폴더를 고르면 재생할 수 있습니다. 선택한 음악은 업로드되거나 저장소에 올라가지 않습니다.

## 내 컴퓨터에서 실행하기

```bash
python serve.py
```

그 뒤 브라우저에서 `http://localhost:8000`을 엽니다. `music` 폴더에 음원과 같은 이름의 `.lrc`, `.srt`, `.vtt`, 앨범 이미지를 넣으면 함께 불러옵니다.

> `music` 폴더는 개인정보 및 저작권 보호를 위해 Git에서 제외되어 있습니다. 공개 저장소에 개인 음원을 넣지 마세요.

## 기능

- YouTube URL 재생
- 음악 폴더 직접 선택 및 로컬 재생
- 자막 파일과 온라인 가사 검색
- 앨범 커버 색상 반영
- 키보드와 LP 다이얼 제어
